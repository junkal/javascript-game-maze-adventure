# Maze Adventure (JavaScript + HTML5)

Maze Adventure is a browser-based maze exploration game built with JavaScript and HTML5 Canvas. Players navigate through a procedurally generated maze, racing against a countdown timer to reach the goal. The game features smooth animations, sound effects, and a clean modular code structure using ES Modules.

## File Structure ##
<pre lang="markdown">
```plaintext
.
├── index.html               # Entry point
├── style.css                # UI and layout
├── assets/                  # Images & audio
├── js/
│   ├── main.js              # Game bootstrap
│   ├── game.js              # Game logic
│   ├── maze.js              # Maze generator
│   ├── player.js            # Player logic
│   ├── game_renderer.js     # Drawing layer
│   └── asset_manager.js     # Asset loader
```
